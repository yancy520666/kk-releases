# kk Translator 发布仓库

kk Translator 是面向课堂与会议场景的实时转写与翻译软件，提供双语字幕、阶段重点与课后笔记。本仓库用于发布 Windows 安装包及自动更新所需的版本信息，不包含源代码。

- 官方网站：[kktranslate.com](https://kktranslate.com)
- 技术支持：[support@kktranslate.com](mailto:support@kktranslate.com)

## 下载与安装

1. 前往 [Releases](../../releases) 页面，选择最新版本（标有 Latest）。
2. 在该版本的 Assets 中下载 `kk-<版本号>-x64-setup.exe`。
3. 运行安装程序，按提示完成安装。

也可以在官方网站的下载页获取同一版本的安装包。

**系统要求：** Windows 64 位（x64）。

## 关于 Windows 安全提示

当前版本尚未进行代码签名，首次运行安装程序时，Windows SmartScreen 可能显示“Windows 已保护你的电脑”。请核对安装包来自本仓库或官方网站后，依次选择“更多信息”和“仍要运行”继续安装。

## 更新

软件会定期自动检查更新，有新版本时在应用内提示并完成更新，无需重新手动下载。各版本的更新内容见对应 Release 的说明。

## 数据与卸载

录音、字幕和笔记保存在你选定的本地资料库文件夹中。卸载 kk Translator 不会删除该文件夹及其中的内容。

## 反馈问题

可在软件内使用问题上报功能，或发送邮件至 [support@kktranslate.com](mailto:support@kktranslate.com)，并尽量附上软件版本号和问题描述。

本仓库仅存放经确认发布的安装包与更新清单，不接受 Issue 和 Pull Request 形式的功能讨论；如有需求请通过上述邮箱联系。
